One original single-line pickup line a robot would say — the joke grows out of being a machine: a robot runs ten thousand simulations of the conversation and still forgets the simplest thing, how to say hello.

> I ran 10,000 simulations of this conversation and in every one I still forgot how to say hello.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 95 characters, within the 200-character cap.
